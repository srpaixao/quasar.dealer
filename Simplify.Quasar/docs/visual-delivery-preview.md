# Padrão visual baseado no Quasar.Delivery

Este é o padrão visual oficial do Quasar.Dealer desde setembro de 2026.

## Acesso

A tela de login é acessada normalmente, sem parâmetros adicionais:

```text
/Account/Login
```

## Escopo visual

- login;
- cabeçalho, menu lateral e rodapé;
- página inicial e indicadores;
- caixas, formulários, botões, tabelas, alertas e paginação;
- comportamento responsivo.

Não há duplicação de controllers, serviços ou regras de negócio. A alteração é
restrita à camada visual da aplicação.
