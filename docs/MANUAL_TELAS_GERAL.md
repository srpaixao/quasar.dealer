Consolidar a lista de manuais por tela disponíveis para consulta operacional e treinamento.

## Cobertura Atual

### Módulos cobertos

- `Recebimento`
- `Estoque`
- `Separação`
- `Expedição`

### Tipos de tela cobertos

- menus
- consultas
- conferências
- movimentações
- fluxos de confirmação

## Observação

Algumas telas do projeto existem em estado parcial ou de estrutura base.

Nesses casos, o manual deixa isso explicito para evitar treinamento incorreto.
